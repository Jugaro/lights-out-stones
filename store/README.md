# Ассеты для магазина приложений

Материалы для страницы Lights Out Stones в сторах (Google Play / RuStore).

| Файл | Назначение | Размер |
|---|---|---|
| `icon-512.png` | Иконка приложения | 512×512 |
| `feature-graphic-1024x500.png` | Feature graphic (баннер страницы приложения) | 1024×500 |
| `shot-game.png` | Скриншот: игровой процесс | телефон, портрет |
| `shot-settings.png` | Скриншот: настройки / новая игра | телефон, портрет |
| `shot-levels.png` | Скриншот: карта уровней кампании | телефон, портрет |
| `listing.md` | Тексты страницы (RU + EN): название, короткое и полное описание | — |

Требования Google Play: иконка 512×512 (PNG 32-бит), feature graphic 1024×500 (PNG/JPEG),
скриншоты — минимум 2, соотношение сторон не более 2:1, короткая сторона ≥ 320px,
короткое описание ≤ 80 символов, полное ≤ 4000 символов.

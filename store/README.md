# Ассеты для магазина приложений

Материалы для страницы Lights Out Stones в сторах (Google Play / RuStore).

| Файл | Назначение | Размер |
|---|---|---|
| `feature-graphic-1024x500.png` | Feature graphic (баннер страницы приложения) | 1024×500 |

соотношение сторон не более 2:1, короткая сторона ≥ 320px.
